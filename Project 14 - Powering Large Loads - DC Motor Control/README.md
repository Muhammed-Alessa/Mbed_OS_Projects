# Powering Large Loads - DC Motor Control

## Description
Uses a low-voltage transistor driver stage to switch a small DC motor from a GPIO output.

## Hardware
- NUCLEO-F446RE
- Small low-voltage DC motor
- Logic-level transistor driver
- Flyback diode
- External low-voltage supply

## Mbed concepts
- `DigitalOut / DigitalIn`
