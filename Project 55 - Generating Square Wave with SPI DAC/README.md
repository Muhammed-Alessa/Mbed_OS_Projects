# Generating Square Wave with SPI DAC

## Description
Sends values to an MCP4921 SPI DAC to generate a square waveform.

## Hardware
- NUCLEO-F446RE
- MCP4921 DAC
- Oscilloscope
- Breadboard and jumper wires

## Mbed concepts
- `SPI`
