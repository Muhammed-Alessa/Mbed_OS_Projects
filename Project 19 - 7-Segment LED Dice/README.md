# 7-Segment LED Dice

## Description
Generates two values from 1 to 6 and presents them on a multiplexed display.

## Hardware
- NUCLEO-F446RE
- 4-digit 7-segment display
- Resistors
- Pushbutton

## Mbed concepts
- `BusOut`
