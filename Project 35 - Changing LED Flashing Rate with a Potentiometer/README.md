# Changing LED Flashing Rate with a Potentiometer

## Description
Maps an analogue potentiometer reading to the user LED blink interval.

## Hardware
- NUCLEO-F446RE
- 10 kohm potentiometer
- Breadboard and jumper wires

## Mbed concepts
- `AnalogIn`
