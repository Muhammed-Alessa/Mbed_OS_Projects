# Using an External Button

## Description
Reads an external pushbutton and controls the user LED.

## Hardware
- NUCLEO-F446RE
- Pushbutton
- 10 kohm resistor
- Breadboard and jumper wires

## Mbed concepts
- `DigitalOut / DigitalIn`
