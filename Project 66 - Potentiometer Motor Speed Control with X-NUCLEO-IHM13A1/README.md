# Potentiometer Motor Speed Control with X-NUCLEO-IHM13A1

## Description
Historical expansion-board project that maps a potentiometer reading to motor speed.

## Hardware
- NUCLEO-F446RE
- Compatible motor expansion board
- Small low-voltage DC motor
- 10 kohm potentiometer

## Mbed concepts
- `Serial`
- `External library`
