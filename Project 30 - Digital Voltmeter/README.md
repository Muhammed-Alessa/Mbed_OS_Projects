# Digital Voltmeter

## Description
Measures a 0-3.3 V analogue input and reports the voltage over serial.

## Hardware
- NUCLEO-F446RE
- 10 kohm potentiometer or 0-3.3 V source
- Breadboard and jumper wires

## Mbed concepts
- `AnalogIn`
