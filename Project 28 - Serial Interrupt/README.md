# Serial Interrupt

## Description
Uses a serial receive interrupt to change the LED flashing rate.

## Hardware
- NUCLEO-F446RE
- USB cable
- Serial terminal

## Mbed concepts
- `Serial`
- `InterruptIn / Ticker`
