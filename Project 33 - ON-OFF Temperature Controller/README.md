# ON-OFF Temperature Controller

## Description
Implements a simple ON/OFF controller around a temperature setpoint using a safe low-voltage indicator output.

## Hardware
- NUCLEO-F446RE
- TMP36
- LED and resistor or low-voltage relay-module input
- Breadboard and jumper wires

## Mbed concepts
- `AnalogIn`
