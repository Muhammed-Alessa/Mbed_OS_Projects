# Light Level Meter

## Description
Uses an LDR voltage divider to estimate ambient light level.

## Hardware
- NUCLEO-F446RE
- LDR
- 10 kohm resistor
- Breadboard and jumper wires

## Mbed concepts
- `AnalogIn`
