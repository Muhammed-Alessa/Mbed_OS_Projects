# Different Flashing a Pair of LEDs Using Mbed Thread

## Description
Runs two LED blink loops as independent Mbed OS 5 threads.

## Hardware
- NUCLEO-F446RE
- 2 LEDs
- 2 resistors

## Mbed concepts
- `RTOS Thread / signals`
