# Electronic Organ

## Description
Maps serial keyboard keys to PWM note frequencies.

## Hardware
- NUCLEO-F446RE
- Passive buzzer
- Small transistor driver
- USB cable

## Mbed concepts
- `Serial`
- `PwmOut`
