# Android-Nucleo Communication Using the ESP-01

## Description
Demonstrates basic serial AT-command communication with an ESP-01 module as a historical Mbed exercise.

## Hardware
- NUCLEO-F446RE
- ESP-01 module
- Proper 3.3 V supply
- Breadboard and jumper wires

## Mbed concepts
- `Serial`
