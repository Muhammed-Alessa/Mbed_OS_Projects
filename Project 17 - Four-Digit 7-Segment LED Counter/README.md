# Four-Digit 7-Segment LED Counter

## Description
Uses a Ticker callback to refresh a four-digit display while a counter changes in the foreground.

## Hardware
- NUCLEO-F446RE
- 4-digit 7-segment display
- Resistors
- 4 NPN transistors
- Breadboard and jumper wires

## Mbed concepts
- `BusOut`
