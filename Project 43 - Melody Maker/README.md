# Melody Maker

## Description
Uses PWM to play a short sequence of musical note frequencies on a passive buzzer.

## Hardware
- NUCLEO-F446RE
- Passive buzzer
- Small transistor driver
- Breadboard and jumper wires

## Mbed concepts
- `PwmOut`
