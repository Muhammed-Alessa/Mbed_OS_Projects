# Sound Level Meter

## Description
Samples an analogue microphone module and measures its peak-to-peak signal.

## Hardware
- NUCLEO-F446RE
- Electret microphone amplifier module
- Breadboard and jumper wires

## Mbed concepts
- `AnalogIn`
