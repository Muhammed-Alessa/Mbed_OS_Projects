# Four-Digit 7-Segment LED Event Counter

## Description
Combines interrupt-driven event counting with periodic display multiplexing.

## Hardware
- NUCLEO-F446RE
- 4-digit 7-segment display
- Pushbutton
- Resistors
- 4 NPN transistors

## Mbed concepts
- `BusOut`
- `InterruptIn / Ticker`
