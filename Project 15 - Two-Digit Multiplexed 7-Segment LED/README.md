# Two-Digit Multiplexed 7-Segment LED

## Description
Multiplexes two 7-segment digits to display a two-digit value.

## Hardware
- NUCLEO-F446RE
- 2-digit 7-segment display
- Resistors
- 2 NPN transistors
- Breadboard and jumper wires

## Mbed concepts
- `BusOut`
