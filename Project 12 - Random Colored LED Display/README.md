# Random Colored LED Display

## Description
Generates changing RGB combinations to create random colors.

## Hardware
- NUCLEO-F446RE
- Common-cathode RGB LED
- 3 x 330-470 ohm resistors
- Breadboard and jumper wires

## Mbed concepts
- `BusOut`
