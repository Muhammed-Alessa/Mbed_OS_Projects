# Simple Stepper Motor Control

## Description
Drives a small 28BYJ-48 stepper through a ULN2003 driver board.

## Hardware
- NUCLEO-F446RE
- 28BYJ-48 stepper motor
- ULN2003 driver board
- 5 V supply

## Mbed concepts
- `BusOut`
