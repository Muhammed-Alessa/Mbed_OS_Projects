# Home IoT Project

## Description
Historical three-node Bluetooth monitoring exercise. One source file can be built as temperature, light, or window node.

## Hardware
- NUCLEO-F446RE
- HC-06-style Bluetooth module
- TMP102 or LDR or switch depending on node

## Mbed concepts
- `Serial`
- `AnalogIn`
