# Car Park Controller Using Signals

## Description
Uses Mbed thread signals to coordinate a simple simulated car-park state machine.

## Hardware
- NUCLEO-F446RE
- 3 pushbuttons
- LED indicator
- USB cable

## Mbed concepts
- `Serial`
- `RTOS Thread / signals`
