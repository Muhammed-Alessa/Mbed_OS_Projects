# Analog Temperature Sensor - Digital Thermometer

## Description
Reads a TMP36 analogue sensor and converts its voltage to temperature.

## Hardware
- NUCLEO-F446RE
- TMP36
- Breadboard and jumper wires

## Mbed concepts
- `AnalogIn`
