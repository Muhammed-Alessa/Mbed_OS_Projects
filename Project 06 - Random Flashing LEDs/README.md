# Random Flashing LEDs

## Description
Shows changing pseudo-random bit patterns on eight LEDs.

## Hardware
- NUCLEO-F446RE
- 8 LEDs
- 8 x 330-470 ohm resistors
- Breadboard and jumper wires

## Mbed concepts
- `BusOut`
