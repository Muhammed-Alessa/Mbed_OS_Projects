# Ultrasonic Height Measurement

## Description
Measures distance with an HC-SR04-style ultrasonic module and displays the calculated result.

## Hardware
- NUCLEO-F446RE
- HC-SR04-compatible ultrasonic module
- 16x2 LCD
- Breadboard and jumper wires

## Mbed concepts
- `External library`
