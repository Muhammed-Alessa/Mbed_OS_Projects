# Two Nucleo Boards Communicating Through UART

## Description
Sends temperature data from one Nucleo board to another over a secondary UART.

## Hardware
- 2 Nucleo boards
- TMP102 or simulated temperature source
- Jumper wires

## Mbed concepts
- `Serial`
