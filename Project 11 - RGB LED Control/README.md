# RGB LED Control

## Description
Uses three buttons to toggle the red, green, and blue channels of an RGB LED.

## Hardware
- NUCLEO-F446RE
- Common-cathode RGB LED
- 3 pushbuttons
- 3 x 330-470 ohm resistors
- Breadboard and jumper wires

## Mbed concepts
- `DigitalOut / DigitalIn`
