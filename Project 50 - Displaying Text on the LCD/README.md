# Displaying Text on the LCD

## Description
Displays a short message on a 16x2 HD44780-compatible LCD.

## Hardware
- NUCLEO-F446RE
- 16x2 LCD
- 10 kohm contrast potentiometer
- Breadboard and jumper wires

## Mbed concepts
- `External library`
