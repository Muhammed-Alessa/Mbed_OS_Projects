# Flashing an External LED

## Description
Drives an external LED from a GPIO pin through a current-limiting resistor.

## Hardware
- NUCLEO-F446RE
- LED
- 330-470 ohm resistor
- Breadboard and jumper wires

## Mbed concepts
- `DigitalOut / DigitalIn`
