# TMP102 Temperature Sensor

## Description
Reads a TMP102 sensor over I2C and reports the temperature over serial.

## Hardware
- NUCLEO-F446RE
- TMP102 breakout
- Breadboard and jumper wires

## Mbed concepts
- `Serial`
- `I2C`
