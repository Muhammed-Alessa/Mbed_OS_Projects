# Android-Nucleo Communication Using the Wi-Fi Expansion Board

## Description
Historical Mbed Wi-Fi expansion-board example preserved as a portfolio placeholder because its original middleware is obsolete.

## Hardware
- NUCLEO-F446RE
- Compatible historical X-NUCLEO Wi-Fi expansion board

## Mbed concepts

- `External library`
