# Waveform Generator

## Description
Provides a serial menu for selecting several DAC waveform types.

## Hardware
- NUCLEO-F446RE
- Oscilloscope
- USB cable
- Serial terminal

## Mbed concepts
- `Serial`
- `AnalogOut`
