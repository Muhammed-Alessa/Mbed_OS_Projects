# Binary Event Counting with LEDs

## Description
Increments an 8-bit LED counter whenever the user button is pressed.

## Hardware
- NUCLEO-F446RE
- 8 LEDs
- 8 x 330-470 ohm resistors
- Breadboard and jumper wires

## Mbed concepts
- `BusOut`
