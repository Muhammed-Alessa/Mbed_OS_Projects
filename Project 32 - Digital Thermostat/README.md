# Digital Thermostat

## Description
Compares measured temperature with upper and lower limits and indicates an out-of-range condition.

## Hardware
- NUCLEO-F446RE
- TMP36
- Breadboard and jumper wires

## Mbed concepts
- `AnalogIn`
