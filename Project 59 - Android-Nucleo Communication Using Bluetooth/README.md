# Android-Nucleo Communication Using Bluetooth

## Description
Receives simple text commands over an HC-06-style serial Bluetooth module and controls two LEDs.

## Hardware
- NUCLEO-F446RE
- HC-06-style Bluetooth module
- 2 LEDs
- 2 resistors
- Breadboard and jumper wires

## Mbed concepts
- `Serial`
