# Calculator Using a Keypad

## Description
Reads calculator input from a 4x4 matrix keypad and displays the result on an LCD.

## Hardware
- NUCLEO-F446RE
- 4x4 matrix keypad
- 16x2 LCD
- Breadboard and jumper wires

## Mbed concepts
- `External library`
