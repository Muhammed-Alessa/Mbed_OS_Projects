# Simple Brushed DC Motor Control

## Description
Turns a small low-voltage brushed DC motor on and off through a suitable driver.

## Hardware
- NUCLEO-F446RE
- Small low-voltage DC motor
- Motor driver/transistor stage
- Flyback protection
- External low-voltage supply

## Mbed concepts
- `DigitalOut / DigitalIn`
