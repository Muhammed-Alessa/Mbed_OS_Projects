# Changing the Motor Rotation Direction

## Description
Controls motor direction through a low-voltage H-bridge driver interface.

## Hardware
- NUCLEO-F446RE
- Small low-voltage DC motor
- H-bridge driver module
- External low-voltage supply

## Mbed concepts
- `DigitalOut / DigitalIn`
